# Rótulos de Triagem (Triage Labels)

As skills operam com base em cinco papéis canônicos de triagem. Este documento mapeia esses papéis para as identificações de estado utilizadas no rastreador de issues deste repositório.

| Papel canônico nas skills | Rótulo no nosso rastreador | Significado                               |
| ------------------------- | -------------------------- | ----------------------------------------- |
| `needs-triage`            | `needs-triage`             | Mantenedor precisa avaliar esta demanda   |
| `needs-info`              | `needs-info`               | Aguardando mais informações do relator    |
| `ready-for-agent`         | `ready-for-agent`          | Totalmente especificado, pronto para o agente autônomo |
| `ready-for-human`         | `ready-for-human`          | Requer implementação humana               |
| `wontfix`                 | `wontfix`                  | Não será implementado                     |

Quando uma skill mencionar um papel (ex.: "aplicar o rótulo de pronto para agente"), utilize a identificação correspondente desta tabela.

Edite a coluna "Rótulo no nosso rastreador" caso decida adotar outro padrão de nomenclatura.
